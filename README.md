# agents-strip

A thin, always-on dashboard for your running [Claude Code](https://docs.claude.com/en/docs/claude-code)
sessions. It paints **one card per session** — state, a short AI-generated summary
of what the agent is doing, its project and its age — plus your **Claude quota** as
labelled progress bars. It lives in a dedicated [Ghostty](https://ghostty.org)
window pinned to the top of a monitor, so you can glance at every agent at once.

```
 AGENTS  · 3 session(s)                                                      14:07

 ▸ RUNNING          │ ◆ WAITING          │ ✔ DONE              CLAUDE QUOTA
 💬 Applying edits   │ 💬 Cypress runner  │ 💬 Wrote release    session [████░░░]  41%
    to source files  │    awaiting relau… │    notes draft              ↻ resets 16:30
 📁 cortex          │ 📁 jahia-modules   │ 📁 academy-docs      weekly  [██░░░░░]  22%
 🕒 just now        │ 🕒 2m ago          │ 🕒 18m ago                   ↻ resets Mon 09:00
```

Click a card to raise that agent's own Ghostty window.

## How it works

- Runs on its **own tmux server** (`tmux -L agents`), so it never touches your main tmux.
- The dashboard is drawn **inside the pane** with ANSI escapes (not as tmux window
  tabs), which is what lets each card be multi-line.
- A refresh loop (`watch`) redraws every few seconds; it discovers sessions from
  `~/.claude/projects/*/*.jsonl` and live `claude` processes (`pgrep` + `lsof`).
- Session **state**: `RUNNING` (file touched < 90s ago), `WAITING` (a live `claude`
  process whose transcript is idle), or `DONE`.
- Each card's summary is generated by **Claude Haiku** (cheapest model), refreshed
  once each time an agent finishes a turn, and cached per session.
- **Clicks** are mapped from the pane x-coordinate back to a card via a colmap file,
  then the matching Ghostty window is raised with AppleScript.
- At login a **LaunchAgent** starts it and snaps it to the top of the right monitor
  using [Magnet](https://magnet.crowdcafe.com/)'s "Very Top" command (with an
  Accessibility-API fallback if Magnet isn't installed).

See [CLAUDE.md](CLAUDE.md) for the full architecture and the non-obvious gotchas —
it's written so an AI assistant can pick up and iterate on this repo in a fresh session.

## Requirements

- **macOS** (uses AppleScript / System Events, `swift`, `open -na`).
- **[Ghostty](https://ghostty.org)** terminal (single-instance on macOS — see CLAUDE.md).
- **tmux**, **python3** (system `/usr/bin/python3` is fine), **swift** (Xcode command-line tools).
- **[Claude Code](https://docs.claude.com/en/docs/claude-code)** CLI at `~/.local/bin/claude`.
- **[Magnet](https://magnet.crowdcafe.com/)** (optional) for the "Very Top" snap.
- **Accessibility permission** for `/usr/bin/osascript` (and Ghostty) so the window
  can be positioned and raised: System Settings → Privacy & Security → Accessibility.

## Install

The files here are the working copies; place them at the paths the script expects.

```bash
# 1. the script + tmux config
mkdir -p ~/.config/tmux
cp agents-strip.sh   ~/.config/tmux/agents-strip.sh
cp agents-strip.conf ~/.config/tmux/agents-strip.conf
chmod +x ~/.config/tmux/agents-strip.sh

# 2. a handy alias (optional)
echo 'alias agents-strip="bash ~/.config/tmux/agents-strip.sh boot"' >> ~/.zshrc

# 3. start at login (edit the plist paths if your username differs)
cp com.fgerthoffert.agents-strip.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.fgerthoffert.agents-strip.plist

# 4. or just launch it now
bash ~/.config/tmux/agents-strip.sh start
```

Grant Accessibility permission when macOS prompts (or add `/usr/bin/osascript` and
`Ghostty` under System Settings → Privacy & Security → Accessibility).

## Subcommands

| Command | What it does |
|---|---|
| `open` | Launch the dedicated Ghostty window on the rightmost screen |
| `boot` | (inside that window) start/attach the strip tmux session |
| `watch` | Refresh loop: redraw the dashboard every few seconds |
| `render W H` | Print one frame for a pane W columns × H rows |
| `click X` | Map pane column X to a card and raise that agent's window |
| `focus <name>` | Raise the Ghostty window whose title matches `<name>` |
| `start` | Login entrypoint: ensure it's running, then position it |
| `position` | (Re)snap the window to the top of the right screen |

Inside the strip, press `r` to force an immediate redraw.

## Customize

- **Font size / zoom:** `--font-size=17` in `open_strip()` (Ghostty default is 13).
- **Which screen:** `screen_geo()` picks the rightmost `NSScreen`; change the Swift
  one-liner for a different monitor.
- **Quota source:** the quota bars read `~/GitHub/Jahia/cortex/local/sessions/*/quota.json`
  — adjust that glob in the `render` Python to point at wherever your quota readings
  live, or remove the block if you don't track quota.
- **Positioning:** `position_strip()` uses Magnet's "Very Top"; the AX fallback sizes
  the window to the top eighth of the screen.
